# 菜单栏单行命令栏设计

## 目标

把当前三组、最多三行的菜单栏改为高频操作优先的单行命令栏，在 Tauri 最小窗口 `900x560` 下仍保持 48px 高度，同时把持续状态移到独立的 24px 底栏。

## 设计

- 左侧保留“打开”下拉、保存、刷新；“打开”统一承载打开文件和打开目录。
- 中间保留阅读、源码、编辑、分屏四种视图的 segmented control。
- 右侧改为“阅读外观”、Plus 设置和“更多”三个图标按钮；Lite 不显示 Plus 设置。
- “阅读外观”承载主题、渲染聚焦和背景图；“更多”承载设为默认、自动保存、沉浸模式、语言切换和渲染引擎信息。
- 底部状态栏显示编码、链接校验、索引、阅读进度和当前状态；沉浸模式和打印时隐藏。
- 用按需引入的 `lucide-svelte` 图标替换 Emoji，按钮保持 tooltip、`aria-label`、`aria-expanded` 和 Escape 关闭行为。

## 兼容与非目标

- 不改变文件打开、保存、刷新、主题、背景图、自动保存、设置面板和沉浸模式的业务逻辑。
- 不改变 Lite/Plus edition 边界，不把 Plus 阅读设置引入 Lite。
- 不重构工作区、侧栏、编辑器或 Markdown 渲染器。
- 仅增加树摇后的图标依赖，构建后比较 Lite/Plus 输出，避免明显体积回退。

## 验收

- 默认 `1280x820` 与最小 `900x560` 下顶部命令栏均为 48px 单行，无重叠或横向滚动。
- 三个弹层可打开、互斥、点击外部或按 Escape 关闭。
- Plus 显示设置按钮，Lite 不显示；所有原有命令仍可访问。
- `npm run check:editions`、`npm run check`、`npm run build:plus`、`npm run build:lite` 通过。
- 在浏览器开发模式中完成桌面和最小窗口截图检查；Tauri 专属 API 报错单独记录，不作为布局失败。
